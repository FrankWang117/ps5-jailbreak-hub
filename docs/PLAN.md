## 当前限制与待处理事项

- 没有通过核验的真实兼容性记录。已核对的产品字段不能替代出厂固件、内部硬件修订或设备实测。
- 双主题首访跟随系统；显式选择保存在本机，暂不提供第三个“自动跟随”切换选项或跨标签实时同步。独立 Host 保持 M0 原生页面，PS5 实机验证仍待后续阶段。
- JSON schema 只能验证结构和声明一致性，不能替代人工核验网页内容。
- 固件输入目前仅接收一至两位整数加两位小数；真实资料使用完整系统软件版本时需明确表示方式和映射规则，禁止无证据转换。
- PS5 Host 未进行实机验证；无部署配置；Web 静态托管需要路由回退。
- M0 安装存在 ESLint 9 弃用、pnpm/esbuild 脚本提示；构建有上游 Zod 注释提示，未阻断检查。依赖维护时另行评估，不通过静默关闭告警替代修复。
