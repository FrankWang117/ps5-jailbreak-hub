## 本轮实现

- 首屏显著展示 Beta 与由数据生成的系列/批次数。首页删除重复的大幅介绍、三卡导航和重复查询按钮，仅保留查询、设备位置与入门指南两条帮助。Host 旧地址保留但不进入主导航。

- `/about` 提供范围、更新日期、资料限制、浏览器保存和 URL 分享说明；清除按钮只删除本站设备与准备记录，主题及其他站点存储保留，存储失败不能声称已彻底删除。
- `/feedback` 提供 GitHub Issues 入口和静态模板，明确公开可见且需要登录。无账号者可手动复制模板，通过找到本站的渠道发送。没有自动携带主机资料、地址栏、日志或完整序列号，也不新增后台。复制不可用时提供手动选择文本。
- 通过已连接 GitHub 只读接口核对现有仓库 `FrankWang117/ps5-jailbreak-hub`：公开、Issues 开启。没有发送消息、创建 Issue、修改仓库设置或上传文件。
- 基础页面标题与描述根据页面/文章切换，演示、开发、反馈、未找到页面及携带参数的查询/回答链接设 noindex；返回普通页面恢复规则。canonical/og:url 不带用户参数，索引允许的页面使用当前站点 origin。未预填虚构域名。
- 静态 HTML 有默认标题、描述与分享元信息，提供 favicon.svg、share-card.svg 和由本站 SVG 本地渲染的 1200×630 share-card.jpg；不是外部图片或实机画面。客户端元信息与静态默认分享信息不等于所有社交抓取器均已验证。真实域名后的绝对分享地址、sitemap 和腾讯云抓取/路由验收仍属未来发布事项。
