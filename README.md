# PS5 Jailbreak Hub

首发定位为 PS5 出厂版本参考工具 Beta（0.1.0-beta.1）。面向中文用户：先查型号、序列号前缀或实际系统版本，再按结果确认设备与阅读准备教程。

教程面向不同 PS5 型号。CFI-2200B01 是保留的首位用户案例，12.40 是该案例的研究假设；二者不是全站适用条件。首次查询不预选型号或版本。

> 可输入其他完整 CFI 型号查询。正式目录目前只有 CFI-2200B01 的已核验型号资料，没有通过核验的兼容性记录；未收录组合显示未知，不继承其他型号或版本的结论。

## 本地运行

Node.js >= 22.12，pnpm 10（固定 10.10.0）。

```sh
pnpm install --frozen-lockfile
pnpm dev
# 也可分别启动
pnpm dev:web
pnpm dev:host
```

腾讯云目录准备见 [部署说明](./docs/tencent-cloud-web.md)：生产地址为 `https://voidbai.com/ps5/`，子域名跳转至此。根 `.env.local` 已配公开路径与地址（不提交），新环境从 `.env.example` 复制；`pnpm package:web` 生成带 `ps5/` 目录和摘要的静态包，`pnpm preview:web` 可本地预览。开发入口仍是 `/`。用户已回传 Nginx 添加片段后语法检查通过、reload 后 active；代理未直接连接服务器；用户已确认原提交 89cc82b 的 Actions 重跑成功，浏览器功能走查和子域名 DNS/证书仍待验收。

自动部署入口已提供：推送 main 后 Actions 执行全套检查，再通过已有 SSH Secrets 调用服务器 `scripts/prod-update.sh`，拉取对应提交、在临时 Docker 容器内构建并切换静态版本（宿主机无需 Node/pnpm）；线上检查失败恢复旧链接。首次需要配置专用目录、Nginx 和本仓库 Secrets，详见上方部署说明。用户已补齐 SSH Secrets、克隆源码并确认生产配置和目录可写；用户已确认 Actions 重跑发布成功（89cc82b）。更新脚本另补最多 3 次拉取重试，持续失败仍停止；本次提交该改进，尚未推送到线上。

服务器用户分工沿用 daily-patch：`ubuntu` 管系统、Nginx 与证书，`deploy` 管应用拉取、构建和发布；发布脚本兼容直接登录 deploy 或从 ubuntu 切换到 deploy，具体权限需服务器确认。

以终端地址为准，Web 默认 `http://127.0.0.1:5173`，独立 Host 默认 `http://127.0.0.1:5174`。Host 当前只是信息页，无漏洞或 Payload 执行。局域网访问与部署需另行配置；PS5 实机未验收。

## 页面与阅读方式

首页首先提供三种快速查询：序列号前缀查出厂批次参考、完整型号查看已收录系列批次、实际版本查正式兼容性。出厂参考位于独立 `@ps5/data/factory` 子路径，目前核查 CFI-20 / 21 / 70 / 71 的 83 个历史批次；不是全部型号覆盖，CFI-2200B01 尚无出厂批次记录。查询前可展开信息位置帮助；页面提前提示当前能力边界。序列号输入固定显示 S01-，只需填后 4 位；也可粘贴完整 S01- 序列号，在本页提取前缀并提示，尾部不保留。输入后点击旁边的“确认查询”，也可按回车提交。前缀不写入 URL、存储或设备记录；估计版本不自动带入实际版本输入。详见 [快速筛查核验](./docs/quick-check-review.md)。

首页保留快速查询与两个帮助入口，Host 已移出主导航。型号批次表默认折叠，按需展开。

`/about` 说明数据范围、浏览器保存项和分享链接边界，支持只清空本站设备/准备记录、保留主题与其他站点存储；`/feedback` 提供公开 GitHub Issues 入口与可复制模板，不自动收集或发送设备信息。来源/反馈范围与本轮检查见 [首发补齐记录](./docs/beta-content-review.md)。

页面具备独立标题/描述、客户端 canonical 与索引规则，演示、开发、反馈与携带回答的 URL 设置 noindex；静态分享图和图标已提供。客户端元信息不等于所有分享抓取器都已验证，真实域名及腾讯云发布验收留到后续。

首页查询后的辅助入口可进入 `/start`：按四步记录型号、主界面与完整版本，由用户核对后查询。有效进度保存在当前浏览器，刷新可继续，支持清空重录；存储不可用时会提示。设备卡在后续查询和阅读中持续显示。保存只代表用户记录，不是兼容性或实机验证。详见 [分步样板检查](./docs/device-guide-review.md)。

`/prepare` 提供电脑与网络准备四步：确认系统、找到地址、记录原设置与连接计划、核对记录。macOS / Windows 有对应查看路径，Linux / 其他系统明确提示菜单资料缺口。网页只保存确认项，地址和原设置留在用户自己的笔记；更换设备或电脑条件清除旧进度。记录不代表网络互通或可安装。见 [电脑与网络准备检查](./docs/preparation-guide-review.md)。

| 入口                          | 用途                               |
| ----------------------------- | ---------------------------------- |
| `/`                           | 型号、前缀与实际版本快速查询       |
| `/prepare`                    | 电脑与网络准备分步引导             |
| `/compatibility`              | 输入型号与版本原文，短版本精确查询 |
| `/knowledge`                  | 九篇中文指南与基础知识             |
| `/knowledge/choosing-a-route` | 回答准备条件，查看缺项与下一步     |
| `/demo/compatibility`         | 明确标识的独立示例目录             |
| `/about`                      | 关于、数据与本地记录说明           |
| `/feedback`                   | 问题反馈与资料纠错                 |
| `/host`                       | 保留旧地址的开发说明，非主导航入口 |

正文保留步骤和必要提醒；来源、发布文件复核、组件研究和游戏案例默认折叠，点击目录可展开定位。旧 `/knowledge/firmware-1240-routes` 链接保留重定向。首次安装与游戏运行仍为待实机验证草稿，不代表所有型号均有可用方案。

Web 支持浅色/深色主题：首访跟随系统，用户选择在本机持久化，存储不可用时仍能切换。静态托管需配置 Web 路由回退；当前未部署。

## 数据与架构

- `apps/web`：React + Vite + TypeScript，Tailwind v4 和本地 shadcn/ui 组件。
- `apps/host`：原生 HTML/CSS/JavaScript，独立静态应用。
- `packages/core`：Zod 校验、精确查询与类型。
- `packages/data`：正式资料、隔离演示与知识库 JSON；Web 不维护第二份数据。

正式与示例分开加载。型号资料不作为破解证据；所有非 unknown 兼容性结论都需要精确对应型号、固件、方案和状态的可靠来源。版本作为字符串比较，`03.00` 与 `3.00` 不隐式等价。完整系统版本原文可保留；没有可靠对应关系时单独提示，不截取、不转换、不查询短版本。

路线页根据型号、版本、能否进入主界面、有无电脑及电脑系统，列出已知信息、缺项与下一步。回答在页面 URL 中保留，刷新可恢复，不表示已具备执行条件。详见 [条件引导检查记录](./docs/intake-guidance-review.md)。

通用输入仅接收 CFI 编号格式，不验证型号是否存在，也不保存为新的正式资料。没有后端、数据库、登录、自动升级或降级功能。
